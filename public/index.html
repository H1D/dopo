Connect Lunch Money

dopo sorts your Lunch Money transactions right here in the browser. Your tokens stay on this device and go only to Lunch Money and OpenRouter — there is no server.

  1. Create a Lunch Money API token (required).
  2. Optionally create an OpenRouter key for AI suggestions — use a dedicated key with a spend limit.

You'll need to be online this first time — after that, dopo keeps working offline and syncs your sorting when you're back.
